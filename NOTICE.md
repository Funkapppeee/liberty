# Notice

Liberty is an independent, unofficial project. It is not affiliated with, authorised by, or
endorsed by Rockstar Games, Take-Two Interactive, or NaturalMotion.

- **No game content is distributed here.** This repository holds only original source code and
  notes. To use it you must own Grand Theft Auto IV and have it installed; Liberty reads your
  installed files in place and never modifies them.
- **No keys.** The game's archives are encrypted. Liberty reads the key from your own `GTAIV.exe`
  at run time, exactly as the game does; the key is not in this repository. The code holds only a
  checksum used to recognise it.
- **No copied code.** Nothing here is taken from the game's executable, from leaked source code,
  or from other projects' source. File formats and behaviour were worked out from the data files
